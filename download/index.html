Installing on a TV box or Fire TV

  1. Install the free Downloader app from your box's app store.
  2. Allow Downloader to install apps: on Fire TV, Settings → My Fire TV → Developer options → Install unknown apps → Downloader → On. On other boxes Android asks the first time.
  3. In Downloader, type the app's code (or its download address) and press Go, then Install.
  4. Open the app and add your playlist. It looks for updates by itself.
